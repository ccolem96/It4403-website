Course: IT 4403

Project Description

This project is a Single Page Application (SPA) built using HTML, CSS, JavaScript, and jQuery AJAX. It uses the Open Library API to allow users to search for books, view book details, and manage a personal bookshelf.

Features

* Search for books by title or author.
* Display book covers, titles, and authors.
* View detailed book information.
* Add books to a personal bookshelf.
* Remove books from the bookshelf.
* Navigate between application sections without full-page reloads.

Technologies Used

* HTML5
* CSS3
* JavaScript
* jQuery
* jQuery AJAX
* Open Library API
* GitHub Pages

Testing
